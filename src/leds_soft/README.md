# Legacy software LED modules

Этот каталог содержит сохранённую программную реализацию управления LED, которая использовалась до перехода на аппаратный PWM.

Она оставлена как исторический материал и не входит в текущую сборку `workshop-5`. Актуальная LED-подсистема находится в `src/leds/`, а аппаратный драйвер — в `src/hardware/pwm/`.

## Состав

| Документация | Исходные файлы | Назначение |
|---|---|---|
| [soft_pwm.md](soft_pwm.md) | `soft_pwm.c/.h` | Формирование PWM опросом из основного цикла |
| [fade.md](fade.md) | `fade.c/.h` | Плавное изменение скважности |
| [led_controller.md](led_controller.md) | `led_controller.c/.h` | Управление фазами и циклами одного LED |
| [led_sequence.md](led_sequence.md) | `led_sequence.c/.h` | Последовательный обход LED |

## Историческая схема

```text
led_sequence
     |
     v
led_controller
     |
     +------> fade
     |          |
     v          v
  soft_pwm <----+
     |
     v
leds_gpio
     |
     v
   GPIO
```

Эта архитектура отличается от текущей: `soft_pwm` формировал логические ON/OFF-состояния программно, а `leds_gpio` переключал GPIO. В текущем `leds_pwm` используется аппаратный PWM и цветовые преобразования RGB/HSV.

Для согласования с текущим расположением GPIO-драйвера старые исходники используют заголовок `leds/leds_gpio.h`. Сам legacy-код не включён в текущий Makefile.
