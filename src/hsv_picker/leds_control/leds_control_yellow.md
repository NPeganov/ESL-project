# leds_control_yellow — контроллер жёлтого LED

## Назначение

Внутренний контроллер управляет яркостью отдельного жёлтого LED и реализует четыре паттерна индикации. Он не знает о режимах HSV Picker: координатор передаёт ему выбранный паттерн.

## Паттерны

| Паттерн | Поведение |
|---|---|
| `LC_YELLOW_OFF` | 0% яркости |
| `LC_YELLOW_ON` | 100% яркости |
| `LC_YELLOW_SLOW_BLINK` | Плавный медленный цикл |
| `LC_YELLOW_FAST_BLINK` | Плавный быстрый цикл |

Параметры мигающих циклов:

| Фаза | Slow | Fast |
|---|---:|---:|
| Fade in | 1000 мс | 150 мс |
| Hold on | 200 мс | 50 мс |
| Fade out | 1000 мс | 150 мс |
| Hold off | 200 мс | 50 мс |
| Полный цикл | 2400 мс | 400 мс |

Fade in и fade out линейные. Яркость задаётся целыми процентами.

## Выбор паттерна

`yellow_set_pattern()` проверяет enum. Для OFF/ON сразу устанавливает 0/100%. Для мигающего паттерна:

1. переводит длительности фаз в app_timer ticks;
2. рассчитывает сумму фаз;
3. сохраняет текущий timestamp как начало нового цикла;
4. устанавливает яркость 0%, начиная с fade-in.

Повторный выбор мигающего паттерна перезапускает цикл с начала.

## Обновление

`yellow_process(now)` вызывается общим 10-мс таймером `leds_control`. Для мигающего паттерна вычисляется позиция внутри цикла:

```c
phase = elapsed_since_start % cycle_ticks;
```

Далее определяется текущая фаза и яркость. Если рассчитанная яркость совпадает с текущей, PWM setter не вызывается.

Использование времени от начала цикла предотвращает накопление фазового дрейфа при задержках timer callback. Контроллер не создаёт собственного таймера и не управляет RGB LED.
