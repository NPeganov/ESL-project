# leds_control — фасад управления светодиодами

## Назначение

`leds_control` — прикладной фасад управления RGB LED и отдельным жёлтым LED. Он инициализирует `leds_pwm`, два внутренних контроллера и один общий периодический таймер.

Модуль не знает о кнопке и не выбирает режим HSV Picker. Это ответственность `hsv_picker`.

## Инициализация

`lc_init()`:

1. запрещает повторную инициализацию;
2. вызывает `leds_pwm_init()`;
3. устанавливает яркость жёлтого LED в 0%;
4. вызывает `hsv_init()` и `yellow_init()`;
5. создаёт repeated app_timer;
6. запускает таймер с периодом 10 мс.

LFCLK и app_timer должны быть подготовлены заранее через `timer_service_init()`. Возвращает false при повторном вызове или ошибке инициализации PWM/timer.

## Публичный API

- `lc_set_hsv(h, s, v)` / `lc_get_hsv(...)` — установка и чтение цвета RGB LED в HSV.
- `lc_start_hsv_change(parameter)` — запуск изменения H/S/V или возобновление того же приостановленного параметра; функция имеет тип `void`.
- `lc_stop_hsv_change()` — пауза активного изменения с сохранением прогресса.
- `lc_set_yellow_pattern(pattern)` — выбор OFF, SLOW_BLINK, FAST_BLINK или ON.

Hue задаётся в градусах 0…359; Saturation и Value — 0…100%. `lc_start_hsv_change()` ничего не возвращает; `lc_set_yellow_pattern()` возвращает false при неинициализированном модуле или недопустимом паттерне.

## Общий таймер

Каждые 10 мс один callback считывает app_timer counter один раз и передаёт один timestamp двум контроллерам:

```c
uint32_t now = app_timer_cnt_get();
hsv_process(now);
yellow_process(now);
```

Оба контроллера используют одну временную шкалу. Собственных таймеров у них нет. Таймер продолжает вызывать обработчики, даже если соответствующий эффект не активен; неактивный обработчик быстро возвращается.

## Разделение состояния

`leds_control` не хранит отдельную копию HSV: актуальное состояние принадлежит `leds_pwm`. Контроллер HSV хранит параметры временного цикла, а контроллер жёлтого LED — выбранный паттерн и его временную фазу.

RGB и жёлтый LED независимы: изменение цвета не влияет на индикацию режима, а переключение режима не меняет RGB.

Подробности алгоритмов: [HSV controller](leds_control_hsv.md), [yellow controller](leds_control_yellow.md).
