# leds_gpio

`leds_gpio` — низкоуровневый модуль непосредственного управления GPIO светодиодов платы PCA10059. Он предоставляет функции включения и выключения по логическому индексу и скрывает соответствие индексов физическим выводам.

## Назначение и границы ответственности

Модуль:

- настраивает GPIO всех светодиодов как выходы;
- включает один светодиод;
- выключает один светодиод;
- выключает все светодиоды.

Модуль не реализует регулировку яркости, PWM, мигание или временные последовательности.

В текущем приложении RGB и жёлтый LED управляются через `leds_pwm`; `leds_gpio` остаётся отдельным низкоуровневым GPIO API и не вызывается из `leds_pwm`.

## Публичный интерфейс

```c
void leds_gpio_init(void);
void leds_gpio_on(uint32_t led_idx);
void leds_gpio_off(uint32_t led_idx);
void leds_gpio_off_all(void);
```

### Инициализация

`leds_gpio_init()` настраивает все выводы из `LEDS_LIST` как выходы и затем выключает все светодиоды.

Функция не возвращает статус. Вызывающий код должен выполнить инициализацию до обращения к остальным функциям модуля.

### Включение и выключение

`leds_gpio_on(led_idx)` включает LED с указанным индексом, а `leds_gpio_off(led_idx)` выключает его. Допустимый диапазон индексов: от 0 до `LEDS_NUMBER - 1`.

Обе функции проверяют индекс через `ASSERT(led_idx < LEDS_NUMBER)`. Это диагностическая проверка; вызывающий код в любом случае обязан передавать корректный индекс.

`leds_gpio_off_all()` последовательно выключает все светодиоды, вызывая `leds_gpio_off()` для каждого индекса.

## Привязка к PCA10059

Соответствие индексов и выводов берётся из board header `pca10059.h`:

| Индекс | Обозначение | Назначение |
|---:|---|---|
| 0 | `LED_1` | отдельный LED |
| 1 | `LED_2` | красный канал RGB |
| 2 | `LED_3` | зелёный канал RGB |
| 3 | `LED_4` | синий канал RGB |

В реализации таблица GPIO формируется из `LEDS_LIST`:

```c
static const uint8_t m_led_list[LEDS_NUMBER] = LEDS_LIST;
```

Публичный API работает с индексами и не требует от вызывающего кода знания номеров GPIO.

## Активный уровень

Для светодиодов PCA10059 используется active-low логика. Активный уровень определяется макросом `LEDS_ACTIVE_STATE` из board header.

Модуль скрывает эту особенность: `leds_gpio_on()` записывает активный уровень, а `leds_gpio_off()` — неактивный.

## Место в архитектуре

```text
leds_gpio
    |
    v
GPIO output
    |
    v
physical LED
```

Это самостоятельный GPIO-драйвер. Он не является нижним уровнем `leds_pwm`: аппаратный PWM конфигурирует используемые GPIO самостоятельно и не вызывает `leds_gpio`.
