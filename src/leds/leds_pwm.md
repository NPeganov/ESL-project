# leds_pwm — LED-драйвер верхнего аппаратного уровня

## Назначение

`leds_pwm` связывает аппаратные PWM-каналы PCA10059 с понятиями жёлтого LED и RGB LED. Он хранит текущие цветовые представления, преобразует HSV/RGB и переводит процент яркости жёлтого LED в PWM duty.

Модуль не реализует мигание, плавные переходы, обработку кнопки или режимы приложения.

## Каналы платы

| PWM channel | Board pin | Назначение |
|---|---|---|
| 0 | `LED_1` | Жёлтый LED |
| 1 | `LED_2` | Красный канал RGB |
| 2 | `LED_3` | Зелёный канал RGB |
| 3 | `LED_4` | Синий канал RGB |

Все каналы сконфигурированы как active-low. Инверсия скрыта в `hardware/pwm`; API `leds_pwm` использует обычную логическую яркость.

## Публичный API

- `leds_pwm_init()` — инициализирует PWM для четырёх LED.
- `leds_pwm_set_rgb(r, g, b)` — задаёт RGB 0…255 и обновляет HSV-кэш.
- `leds_pwm_set_hsv(h, s, v)` — задаёт H 0…359°, S/V 0…100% и обновляет RGB-кэш.
- `leds_pwm_get_rgb()` / `leds_pwm_get_hsv()` — возвращают кэшированное представление цвета.
- `leds_pwm_set_yellow_brightness(percent)` — задаёт жёлтому LED 0…100%.
- `leds_pwm_get_yellow_brightness()` — возвращает сохранённое процентное значение.

До остальных функций требуется успешный `leds_pwm_init()`. Диапазоны и ненулевые getter pointers проверяются через ASSERT. Инициализация рассчитана на один вызов.

## Хранение цветового состояния

Модуль хранит `m_rgb` и `m_hsv`. При установке одного представления второе вычисляется через `color`. Getter возвращает сохранённое представление, а не повторно конвертирует значение. Это важно из-за целочисленного округления: обратное преобразование не обязано восстанавливать исходные значения точно.

Жёлтая яркость хранится отдельно и не влияет на RGB/HSV.

## Преобразование в PWM

RGB-компоненты напрямую передаются в PWM channels 1–3. Жёлтая яркость сначала переводится из процентов в 0…255, затем передаётся в channel 0.

`leds_pwm` не владеет таймером. Установка значения меняет запрошенный duty; аппаратная генерация PWM продолжается независимо от main loop.

## Зависимости

- `hardware/pwm` — конфигурация каналов и генерация PWM;
- `internal/color` — преобразования HSV/RGB и процентная шкала;
- `pca10059.h` — определения физических LED pins;
- Nordic ASSERT — проверка предусловий.

`hardware/leds_gpio` не используется как нижний слой: PWM драйвер сам конфигурирует свои output pins.
