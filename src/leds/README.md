# Application

Документация приложения и его модулей.

## main

- [main.md](main.md) — подробное описание точки входа приложения, порядка инициализации, главного цикла, обработки событий кнопки, управления LED-последовательностью и полной архитектурной схемы от main до физических GPIO.

## LEDs

Модуль управления светодиодами и яркостью состоит из нескольких частей:

- [leds.md](leds.md) — подробное описание API, конфигурации платы, соответствия логических индексов GPIO и принципа управления физическими выходами;
- [soft_pwm.md](soft_pwm.md) — подробное описание программного PWM, временной модели, расчёта скважности, переходов между режимами, обработки фаз и ограничений;
- [fade.md](fade.md) — подробное описание линейного изменения скважности, дискретной временной модели, паузы, возобновления и взаимодействия с soft_pwm;
- [led_controller.md](led_controller.md) — подробное описание состояний, фаз, жизненного цикла последовательности и взаимодействия fade, soft_pwm и leds;
- [led_sequence.md](led_sequence.md) — подробное описание выбора LED, чтения количества циклов из device_id, переходов между LED, межсветодиодной паузы и взаимодействия с led_controller;
- leds.h / leds.c — публичный интерфейс и реализация управления GPIO;
- soft_pwm.h / soft_pwm.c — публичный интерфейс и реализация программного PWM;
- fade.h / fade.c — публичный интерфейс и реализация плавного изменения скважности;
- led_controller.h / led_controller.c — публичный интерфейс и реализация контроллера последовательности одного светодиода;
- led_sequence.h / led_sequence.c — публичный интерфейс и реализация последовательности светодиодов.

## Ответственность модулей

- leds отвечает за непосредственное управление GPIO светодиодов, логические индексы, соответствие выводам платы и активный уровень.
- soft_pwm формирует логическое PWM-состояние по заданным периоду и скважности.
- fade рассчитывает изменение скважности во времени.
- led_controller связывает PWM и fade с выбранным светодиодом.
- led_sequence управляет выбором светодиодов и последовательностью работы контроллера.

## Конфигурация платы

Текущая конфигурация рассчитана на PCA10059. Количество светодиодов, список GPIO и активный уровень берутся из pca10059.h.

Внешний код использует логические индексы и не должен самостоятельно обращаться к GPIO светодиодов.
