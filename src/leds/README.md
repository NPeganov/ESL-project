# LED modules

В актуальной структуре LED-подсистема разделена на независимые способы управления физическими выходами.

## Актуальные модули

- [leds_gpio.md](leds_gpio.md) — прямое управление GPIO светодиодов.
- [leds_pwm.md](leds_pwm.md) — управление жёлтым и RGB-светодиодами через аппаратный PWM.
- [internal/color.md](internal/color.md) — целочисленные преобразования RGB/HSV, используемые `leds_pwm`.

## Границы ответственности

```text
Application
   |
   +----------------------+
   |                      |
   v                      v
leds_gpio              leds_pwm
   |                      |
   v                      v
GPIO                  hardware/pwm
                          |
                          v
                       PWM0
                          |
                          v
                         GPIO
```

`leds_gpio` и `leds_pwm` — самостоятельные интерфейсы к одним и тем же физическим светодиодам. `leds_pwm` не вызывает функции `leds_gpio`: аппаратный PWM сам конфигурирует назначенные ему GPIO.

`color` находится в каталоге `internal`, поскольку это вычислительная зависимость `leds_pwm`, а не отдельный прикладной API.
